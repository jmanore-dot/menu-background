# Menu Background Picker

Adds a button to the main menu's bottom bar. Click it to:

- **Add Image** – pick a PNG/JPG from your computer to use as the menu background
- **Arrows** – switch between your saved images (and the default background)
- **Remove** – delete the currently selected image
- **Default** – go back to the normal GD menu background

Images are copied into the mod's save folder, so you can move or delete the originals.
